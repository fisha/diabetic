11 · Design system

Design tokens

Direction B, clean white with day and night. One token set feeds both the Expo app (TypeScript theme object) and the Next.js site (CSS custom properties generated from the same JSON). Every colour token has a day and a night value, switched with useColorScheme on native and a data-theme attribute on web. Accent and clinical colours are separate families, and glucose states never rely on colour alone.

11.5

Scripts

The app uses the platform system font in every script (San Francisco on iOS, Roboto and Noto on Android); the web falls back to Inter, Heebo and IBM Plex Sans Arabic. Never apply letter-spacing or uppercase to Arabic or Hebrew. Numbers with units are isolated LTR runs inside RTL text.
